# Frozen reference-shift artifact

`local_reference_shift_main.tex` is the accepted ten-replication frozen-chart
stress-test table used in the submitted article. Its original raw generator is
not present in the final development archive. It is retained here as an
immutable provenance artifact and is not represented as independently
regenerable.

The subsequent rolling-refit reference-drift experiment is fully reproducible
from `scripts/run_simulations.py`, uses 50 independent replications, and is
stored under `results/reference/rolling_drift/`.
