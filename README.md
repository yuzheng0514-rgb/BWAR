# BWAR

Code accompanying **Bures--Wasserstein Autoregression for Gaussian
Distributional Time Series** by Yuzheng Dong, Junlie Huang, and Cheng Meng.

The repository contains the ridge Yule--Walker BWAR implementation, simulation
programs, the Divvy rolling-origin analysis, and scripts for producing the
empirical tables and figures.

## Structure

- `src/bwar/`: Bures--Wasserstein geometry and forecasting methods.
- `scripts/run_simulations.py`: simulation studies.
- `scripts/run_divvy.py`: Divvy analysis and paired bootstrap uncertainty summaries.
- `scripts/build_divvy_background_figure.py`: descriptive Divvy visualization and source-data summaries.
- `scripts/build_artifacts.py`: tables and figures from the included summaries.
- `configs/`: reported experimental settings.
- `results/reference/`: compact numerical results used by the plotting script.

## Installation

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -e .
```

## Simulations

```bash
make smoke        # one-replication check
make simulations  # reported simulation settings
```

## Divvy application

```bash
PYTHONPATH=src python scripts/download_divvy.py
make divvy
```

The download script retrieves the official 2024 Divvy trip archives and
verifies their checksums. Raw data are not redistributed.

## Tables and figures

```bash
make figures
make data-figure  # after the Divvy download step
```

Generated files are written under `artifacts/generated/`. See
`REPRODUCIBILITY.md` for the article-item map.

The fixed-reference Bures, Log-Euclidean, and Cholesky generating mechanisms,
the rolling-refit reference-drift experiment, and the gradual-drift strength
analysis are generated by `scripts/run_simulations.py`.
